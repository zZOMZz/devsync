# 终端交互

## 配置向导

运行 `devsync init` 或 `devsync config`。开始时暂停当前项目同步，已有连接信息作为可编辑默认值；配置保存后仍保持暂停。

1. 选择 SSH 别名，或选择“手动输入地址”。
2. 编辑账号和端口。输入无效时在当前字段修正。
3. 选择认证方式：SSH config/agent、指定私钥（macOS/Linux）或密码。
4. 验证连接，再编辑并验证远端项目路径。连接或目录错误只修正相关项。
5. 选择备份策略：自动备份（默认保留 3 份）、关闭备份或自定义保留数量。
6. 检查范围摘要，明确选择保存或取消。

方向键移动选项，回车确认。文本框中的原值可直接编辑；密码只显示掩码，回车保留旧密码时不会把旧密码放入输入框。配置确认默认选中“保存配置”，直接回车即可保存，也可选择“暂不保存”。页面会提示保存后不会开始同步；纯文本终端使用同样的默认值（`[Y/n]`）。

Esc 取消当前向导；Ctrl+C 中断。取消不保存草稿，已暂停的同步保持暂停。终端光标、输入模式和项目命令锁会被清理。终止发生在同步执行阶段时，用 `devsync status` 确认当前状态。

## 预览和同步

`devsync preview` 暂停自动同步，展示本地/远端目录、认证方式、环境文件策略，以及新增、覆盖、删除三组清单。每组最多显示 15 项，其余项明确提示，完整结果在项目 `.sync/preview.json` 中。删除数量会突出显示。

`sync/start` 在需要首次确认或配置变更确认时使用同样的预览，并默认选中取消。需要备份时展示候选文件数、估算原始大小和保留数量，可以选择“备份后同步”或“跳过本次备份，直接同步”；跳过不会修改项目策略。不需要备份时说明原因，再确认是否直接同步。配置向导的“保存”不会直接启动同步。

连接检查、目录检查、差异扫描、备份和同步有统一的阶段提示。下载阶段保留真实进度、速度、预计剩余时间或停滞提示；无法量化的阶段显示等待时间。

## 终端兼容与脚本

- 正常交互终端使用 Clack 选择和输入组件。窄终端会隐藏选项的辅助说明，并换行展示长摘要。
- `NO_COLOR=1` 关闭颜色，键盘交互继续可用。
- `TERM=dumb` 使用序号选择、普通输入和不带光标控制的进度文本。
- 配置要求标准输入/输出连接到终端，重定向配置命令会在暂停或写入前拒绝。
- `--json` 不输出向导、日志或进度。非交互同步需要确认时，返回 `CONFIRMATION_REQUIRED`；明确使用 `--yes` 后按项目备份策略执行预览、备份和同步流程。

运行时仍要求 Node.js 18+。源码先执行 `npm ci`；交互依赖及传递依赖随 `npm pack` 生成的包一起分发，目标机器无需为业务项目添加依赖。
